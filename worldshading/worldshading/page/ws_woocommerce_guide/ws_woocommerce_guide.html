Use this guide to prepare an Item, check its website stock and price, and bring WooCommerce orders into ERPNext.

ERPNext → WooCommerce: available stock and regular prices.
WooCommerce → ERPNext: orders become draft Sales Orders for your team to review.

Start with one Item. Preview it, sync it, then place one test order. Once that works, prepare the remaining Items using the same checklist.

1. Check the settings

  1. Open WS WooCommerce Settings. Confirm the store and company, then click Test Connection.
  2. Select the selling Price List and the Online Stock Warehouses. Include the Default Order Warehouse in that selection.
  3. Set Import Orders Created Since in the ERP site timezone. Use Now to start with new orders; the connector converts this to UTC internally.
  4. Leave Automatic Sync off while preparing and testing Items. Keep the old built-in Woocommerce Settings sync disabled.

Enable Connector allows manual actions. Automatic Sync allows background updates and order imports when the background services are running.

2. Prepare each Item

Open the existing ERPNext Item and find its WooCommerce section. This connector links existing products; it does not create website products, descriptions or images.

  1. Confirm the exact product. Check size, colour and selling unit in both systems. Use a sellable Item or Item variant, rather than an ERP template.
  2. Check the Item UOM table. Add or correct the normal ERP conversion there first. Then choose the website selling unit in the WooCommerce link.
  3. Add a row in WooCommerce Links. Fill the fields below, save the Item, then preview it.
FieldWhat to enter
EnabledTick when this link is ready to use.
Woo Product IDThe website product ID. For a variation, use its parent product ID here.
Woo Variation IDThe exact variation ID for a size/colour option. Use 0 for a simple product.
Woo SKUThe exact SKU of that product or variation in WooCommerce.
Selling UOMThe unit sold online, such as Each, Roll or Kg. Conversion comes from the Item UOM table.
Sync StockLet ERPNext update website availability.
Sync PriceEnable only when an approved Item Price exists in the configured price list and currency.
Clear Sale PriceWhen price sync is enabled, tick only if ERPNext should remove the Woo promotional sale price. Otherwise an existing Woo sale price can still affect the selling price.

Bulk linking: give every sellable website product or variation its own SKU, matching the ERP Item Code exactly. Open Settings → WooCommerce → Link Matching Items, run the preview, review Ready and Review rows, select approved rows, then Create Reviewed Links. Preview pauses after at most 25 results or ten catalog requests. Next Batch continues; Save Preview and Resume Saved Preview keep the current batch in this browser for 24 hours. These links are active for stock only; price sync remains off. A valid Sales UOM is preferred; otherwise only a sole valid unit is used. Existing links are preserved.

Manual linking: the WooCommerce manager link opens all variations together. Choose an ERP Item and selling unit per row, select the rows to save, then Save Links. New manual links remain inactive for review.

Find IDs and SKUs in the WooCommerce product editor; variations have their own IDs and SKUs. Link each Woo target once. Each ERP Item supports one enabled stock-sync link.

No approved ERP price yet? Start with Sync Stock on and Sync Price off. Add the price later; do not enter a guessed price to complete the setup.

3. Preview, then sync

  1. Save the Item and open WooCommerce → Preview WooCommerce. Compare WooCommerce now with ERPNext value, and check the warehouse list.
  2. Use Open product in WooCommerce in the preview to confirm the correct product.
  3. If the values are right, open WooCommerce → Sync WooCommerce. Preview again to confirm they match.

Preview changes nothing. Sync checks recent website orders before publishing stock. Item status shows the last website attempt or successful check.

4. Check a website order

  1. Place an order for a linked product on the website and note the Woo order number.
  2. In manual mode, click Import Orders in connector settings.
  3. Open Order Inbox, find that number and open its linked Sales Order.
  4. Check the customer, Items, UOMs, quantities, prices, VAT, shipping and total before proceeding with your normal ERP workflow.

Orders are imported as drafts. Reimporting the same Woo order uses its existing inbox record and linked Sales Order. The connector does not automatically post invoices, payments or deliveries.

Customer matching uses a Woo identity scoped to the connected store. Existing connector customer links are still recognised. Matching existing ERP customers by email or mobile is a later enhancement. Changes to a submitted or manually edited imported order can require review.

5. Understand website stock

Website stock is the available quantity from your selected online warehouses, after ERP reservations. The connector also deducts imported Woo draft-order quantities and any configured safety stock, then converts to the selling UOM.

  • A submitted Sales Order reduces availability through ERP reservations, even before delivery.
  • Imported Woo drafts are held separately so the same units are not offered again.
  • The connector includes other supported ERP reservation fields, such as production reservations.
  • Website quantities are whole selling units. For example, 2.8 available rolls publishes as 2 rolls.

Orders needing review hold stock exports for the affected Items. Unrelated Items and enabled price updates can continue. If an order's product identity cannot be read safely, stock may be held more broadly.

6. Prepare prices and VAT

Maintain the approved Item Price excluding VAT in the connector's selected price list and currency. The connector uses that price and the Item UOM conversion when needed.

WooCommerce should accept prices excluding tax and display prices including tax, with the correct tax rate and product tax class. Woo calculates the displayed VAT-inclusive price; do not add VAT again to the ERP Item Price.

Example only: BHD 1.000 net with 10% VAT displays as BHD 1.100. Confirm the correct tax treatment for each product. Confirm the tax class and storefront/cart display before enabling price sync.

BHD prices use three decimal places. Imported order totals are checked against Woo totals. Broader ERP rounding policy changes are a separate task.

7. Turn on automatic operation when ready

After your manual checks pass, enable Automatic Sync and save Settings. The background services must also be running.

  • Normal changes: stock entries, Sales Order reservation events, Item Prices and Item changes queue updates after ERP saves. Only affected linked Items are processed; repeated notifications are combined.
  • Timing: updates start after commit when a worker is available. Website response time and queue backlog affect completion.
  • Recovery: the native ERP scheduler queues a recovery check every ten minutes. It compares local values and catches failures and changes that bypass normal events, including ERPNext v12 order close/reopen. Hourly verification catches website-side changes within the bounded product queue. It does not republish every product every ten minutes. Confirm short and long workers and the ERP scheduler are running; retire the old external connector timer.
  • Orders: an arriving Woo webhook wakes import processing. Delivery depends on the website background services; polling also recovers missed orders.

Optional SKU matching: Automatically Link Matching SKUs is off by default. After accepting the bulk preview, enable it if future exact matches should be linked without another preview. Native recovery scans bounded catalog batches and revisits completed scans after an hour. It never scans the catalog on a stock-change event.

Turning Automatic Sync off pauses automatic imports and exports. You can still use the manual buttons. This guide is static: check Settings for the current operating mode.

8. When something needs attention

An order says Needs Review, or an Item says Stock Held

Open that order in Order Inbox. Read the error and its Product mappings checklist. Correct every missing Item link or UOM, then click Retry Import. Do not ignore a real order simply to release stock.

The SKU or variation does not match

Check the Woo parent product ID, exact variation ID and SKU against the website editor. Save the corrected Item link and preview again. Do not link a similar-looking product without checking its size and unit.

The price is missing or different

Check Sync Price, price list, currency, validity dates and selling UOM. The price must be a general selling price rather than a customer-specific price. Also check Woo VAT settings and any active sale price.

Automatic updates have stopped

Check Enable Connector and Automatic Sync in Settings. Read Sync Logs, then try Test Connection. Ask the administrator to check the background worker and recovery service. Failed updates remain pending for retry; manual Sync can help diagnose an Item.

What should I finish before adding more Items?

Confirm the exact product/variation, SKU, selling UOM and conversion, online warehouses, approved net price if enabled, and product tax class. Then complete Preview → Sync → test order → ERP Sales Order review for one Item before repeating the setup.
